# 🗄️ SQL Mastery & Business Intelligence Queries

This repository contains a structured collection of SQL scripts developed during my Data Analytics journey. It covers everything from basic CRUD operations to advanced analytical functions and database optimization techniques.

## 🚀 Key Learning Milestones

### 1. Fundamentals & Data Manipulation
- **Basic Queries:** `01_sql_basic.sql` & `02_sql_basic_additional.sql`
- **Joins & Relationships:** Mastery of INNER, LEFT, RIGHT, and FULL joins through practical tasks (`03_sql_joins_tasks.sql`, `04_sql_joins_tasks_part_2.sql`).

### 2. Advanced Analytical SQL
- **Complex Logic:** Implementation of Subqueries and Common Table Expressions (CTEs) for multi-step analysis (`06_mysql_subquery_cte_tasks`).
- **Window Functions:** Utilizing `OVER()`, `PARTITION BY`, and `RANK()` for deep data insights (`10_windows_functions_practice.sql`, `2025-12-11-window-functions-exercise.sql`).
- **MySQL Functions:** Extensive use of date, string, and numeric functions for data transformation (`05_mysql_functions_tasks.sql`).

### 3. Business Case Studies (AdventureWorks 2019 & Sakila)
- **KPI Analysis:** Calculating business-critical metrics and performance indicators (`09_mysql_adventure_works_2019_kpi.sql`).
- **Profitability Over Time:** Analysis of product category performance across different periods (`11-1` to `11-3_product_category_profitability_over_time.sql`).
- **Marketing Analysis:** Evaluating campaign effectiveness and customer behavior (`12_adv2019_marketing_analysis.sql`).

### 4. Performance & Optimization
- **Query Optimization:** Refactoring slow queries for better performance and efficiency (`15_adv2019_query_optimisation.sql`).
- **Database Design:** Understanding database structures and schema tasks (`14_mysql_databases_task.md`).

## 🛠️ Databases Used
- **Sakila DB:** A classic database for practicing DVD rental store business logic.
- **AdventureWorks 2019:** A complex, real-world-like database used to simulate manufacturing and sales scenarios.
