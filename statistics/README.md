# 📈 Statistical Analysis for Data Decision Making

This repository documents my journey through business statistics, from basic descriptive analytics to advanced hypothesis testing and regression modeling. These methods are the foundation for extracting reliable insights from noisy data.

## 🔬 Topics & Modules

### 1. Descriptive & Business Statistics
- **Foundations:** Calculating measures of central tendency (Mean, Median, Mode) and dispersion (Variance, Standard Deviation) (`Descriptive Statistics_data.ipynb`).
- **Advanced Averages:** Application of Geometric, Harmonic, and Weighted means for specific business scenarios (`geometric_harmonic_weighted.ipynb`).
- **Exploratory Data Analysis (EDA):** Deep dives into dataset structures and distributions (`EDA_Demos.ipynb`).

### 2. Inferential Statistics & Hypothesis Testing
- **A/B Testing:** Analyzing marketing data to compare performance and test null vs. alternative hypotheses (`PI_H0-H1_AB testing_Marketing_data.ipynb`).
- **Confidence Intervals:** Determining the precision of estimates and population parameters using Python (`confidence_intervals_python.ipynb`).
- **Statistical Libraries:** Using `SciPy` and `Statsmodels` for rigorous mathematical testing (`basic_statistics_spicy_stats.ipynb`).

### 3. Predictive Analytics & Modeling (In Progress 🚧)
- **Regression Analysis:** Studying relationships between variables to predict future outcomes (`regression_statistics` folder).
- **Probability Distributions:** Understanding data patterns (Normal, Binomial, Poisson).

## 🛠️ Tech Stack
- **Python Libraries:** `SciPy`, `Statsmodels`, `NumPy`, `Pandas`, `Matplotlib`.
- **Methods:** T-tests, Z-tests, P-value interpretation, Correlation analysis.
