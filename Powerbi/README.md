# 📊 Power BI: Business Intelligence & Data Modeling

This repository showcases my ability to transform raw data into interactive business insights. The projects cover the full BI lifecycle: Data extraction (SQL/Web/Excel), Data Transformation (Power Query), Data Modeling (Star Schema), and advanced Visualization (DAX & Interactive Dashboards).

## 📁 Projects Overview

### 1. Sales Analysis Executive Report
A comprehensive report designed to provide a 360-degree view of business performance.
- **Pages:** Sales Overview, Customer Details, Product Details.
- **Core Features:**
  - **Data Modeling:** Built a semantic star schema model for optimized performance.
  - **Advanced DAX:** Created measures for Sales YTD, YoY Growth, and Rolling Averages.
  - **Interactivity:** Integrated **Bookmarks** for custom views, **Navigation** buttons, and **Drill-through** for deep-dive analysis.
  - **Data Source:** Integrated and cleaned data from multiple sources using **Power Query**.

### 2. Sakila DB: SQL-to-Dashboard Workflow
A project focused on the synergy between database querying and visualization.
- **Workflow:** - Wrote complex SQL queries to extract relational data from the MySQL Sakila database.
  - Performed data shaping in Power Query.
  - Selected optimal visualizations to represent rental trends and customer demographics.

## 🛠️ Technical Competencies
- **Power Query (M):** Merging, pivoting, and cleaning data from disparate sources.
- **Data Modeling:** Establishing relationships (1:many), managing filter directions, and creating hierarchies.
- **DAX (Data Analysis Expressions):** Calculated columns and measures for complex business logic.
- **UI/UX for BI:** Designing intuitive layouts with consistent themes and navigation.
